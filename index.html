▶ How to get your API Key & Sheet ID (5 minutes)
  1. Go to console.cloud.google.com → Create a project
  2. Search Google Sheets API → Enable it
  3. Go to APIs & Services → Credentials → Create API Key
  4. Restrict the key to Google Sheets API only (recommended)
  5. Open your Google Sheet → copy the ID from the URL:
    docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit
  6. Make the Google Sheet Anyone with link can view (Share settings)
